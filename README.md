# 微光日记 · Weiguang Diary

> 一款极致轻量的睡前正向语音记录工具。点一下通知，说一句话，然后被温柔地肯定。

**在线体验**：https://yvette1202.github.io/weiguang-diary/

---

## 这是什么

「微光日记」是一个只有一个 HTML 文件的小站。它不做复杂的日记、不做打卡排行榜、不做反思复盘。

它只做一件事：**每天睡前，用 30 秒语音，记录一件今天值得肯定的小事，然后被好好鼓励一下。**

深夜打开，暖黄色的小太阳在呼吸，你说的话会实时变成文字，说完点一下按钮，它就替你收好，第二天还会攒成周报给你看。

---

## 为什么做这个

我自己试过很多日记 App：
- 写不下去，因为打字太累；
- 坚持不下来，因为要主动打开 App 就已经有心理负担；
- 复盘类工具总是让我反思"今天哪里没做好"，越想越焦虑；
- 同类产品功能越做越重，反而违背了"轻松记录"的初衷。

所以这个项目反着来：

| 传统日记 / 复盘 App | 微光日记 |
| --- | --- |
| 主动打开 App，打字写 | 点通知直接开口，全程语音 |
| 多步操作、多种模板 | 进入即录，说完即走 |
| 反思问题、压力大 | 只问正向问题，不评价 |
| 显示"漏打卡"、催更 | 不催、不补、不焦虑 |
| 功能越多越好 | 功能越少越好 |

## 功能一览

### 🌅 今日 · 睡前入口
- 暖黄色小太阳呼吸动画，深夜不刺眼
- 每天一个正向引导问题（随机轮换 7 条），不用想"该写什么"
- 点「说给微光听」直接进入录制

### 🎙️ 录制中
- 进入页面自动开始，无需点"开始录音"
- **实时语音转文字**（基于浏览器 Web Speech API，中文识别）
- 声波波形动画 + 计时器
- 说完点「说完了，收好」，全程不超过 3 次操作

### 💛 即时鼓励
- 保存后随机弹出一句温暖的肯定
- 2.5 秒后自动回到首页，不打扰
- 没有"分享到朋友圈"、没有"连续打卡 X 天"的压力

### 📜 时光 · 历史记录
- 按时间倒序浏览每一条微光
- 每条显示日期、文字内容、时长
- 所有数据默认保存在浏览器本地，不上传服务器

### 📅 周报 · 这一周的光
- 每周自动生成一份温暖总结
- 统计微光天数、总时长、高光瞬间
- 提取 1–2 个软标签（坚持小能手、生活发现家、温柔待己……）
- 攒起你说过的最暖三句

### ⚙️ 设置
- 睡前提醒开关与时间
- 仅正向引导模式（不反思、不批评）
- 本地存储状态说明

## 快速开始

### 在线体验（推荐）
直接打开：https://yvette1202.github.io/weiguang-diary/

> 首次使用浏览器会请求麦克风权限，请选择「允许」，否则无法使用实时语音转写。

### 本地运行
1. 下载 `index.html` 到本地
2. 用 Chrome 或 Edge 双击打开即可
3. 不需要任何构建、不需要安装依赖

> 推荐 Chrome / Edge 最新版。Firefox、Safari 也能打开，但 Web Speech API 的中文识别在 Chromium 内核下最稳。

## 使用说明

### 每天的一次完整流程
1. 睡前收到提醒（或主动打开网页）
2. 看到小太阳和当天的引导问题
3. 点「说给微光听」
4. 浏览器请求麦克风权限 → 允许
5. 对着手机说今天最有成就感的一件小事
6. 看着文字实时跳出来
7. 说完点「说完了，收好」
8. 看一句温暖的话，然后晚安

### 没有录到怎么办
- 如果麦克风被拒绝或浏览器不支持实时转写，页面会自动降级到"演示模式"，标签会明确提示
- 重新打开浏览器设置，允许该网站使用麦克风即可

### 数据存在哪里
- 所有记录、设置都只保存在你自己的浏览器里（localStorage / IndexedDB）
- 不上传任何服务器、不需要注册、不需要登录
- 换浏览器、清缓存会清空记录，属于设计如此

## 技术栈

- **单文件 HTML**：所有 CSS、JS、SVG 全部内联，一个文件就是整个应用
- **Tailwind 风格的设计 Token**：手写 CSS 变量，无构建工具
- **Noto Serif SC + Noto Sans SC**：思源宋体做标题，黑体做正文
- **Web Speech API**：浏览器原生 `SpeechRecognition`，中文实时转写
- **纯前端**：无后端、无数据库、无框架、无 npm 依赖
- **GitHub Pages**：直接托管在 main 分支 root 目录

---

## 设计理念

1. **减法优先**：每加一个功能前先问"能不能不加"。
2. **深夜友好**：深暖棕底色，小太阳是唯一亮色，不刺眼。
3. **零心理负担**：没有红色感叹号、没有漏打卡、没有"你已经 3 天没记录了"。
4. **正向心理暗示**：所有引导问题都在问"今天哪里好"，不问"今天哪里错"。
5. **本地优先**：你的声音和文字属于你自己，不进任何云。
